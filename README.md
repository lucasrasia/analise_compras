# Análise de Dados de uma Loja

## Sobre o projeto

Este projeto consiste em uma análise exploratória de dados de uma loja fictícia, desenvolvida com Python e ferramentas do ecossistema de análise de dados.

O projeto foi realizado com o objetivo de colocar em prática e consolidar os conhecimentos adquiridos durante o curso de **Python para Análise de Dados do AKCIT**, explorando desde o tratamento e organização dos dados até a análise e visualização das informações.

## Objetivos

* Realizar a exploração e análise dos dados da loja;
* Identificar padrões e tendências presentes nos dados;
* Analisar indicadores relacionados às vendas;
* Criar visualizações para facilitar a interpretação dos dados;
* Praticar conceitos de Análise Exploratória de Dados (EDA);
* Aplicar conhecimentos de Python em um projeto prático.

## Tecnologias e ferramentas

* **Python**
* **Pandas** — manipulação e análise dos dados;
* **NumPy** — operações e processamento numérico;
* **Matplotlib** — criação de visualizações e gráficos;
* **Jupyter Notebook** — desenvolvimento e documentação da análise.

## Etapas da análise

O projeto foi desenvolvido seguindo algumas etapas principais:

1. Carregamento e inspeção inicial dos dados;
2. Identificação e tratamento de possíveis inconsistências;
3. Análise exploratória dos dados;
4. Aplicação de métodos de agregação e agrupamento;
5. Criação de gráficos e visualizações;
6. Interpretação dos resultados encontrados.

## Principais resultados

Durante a análise, foram explorados diferentes aspectos relacionados aos dados da loja, buscando identificar informações relevantes sobre o desempenho das vendas e o comportamento dos dados.

Entre os principais pontos analisados estão:

* <A pouca aderência do público feminino na região centro-Oeste>;
* <O Faturamento do categoria de elotronicos e móveis é desproporcionalmente maior que as outras categorias que sâo vendidas>;
* <As compras de maior valor recebm em quase totalidade avaliações positivas>.

As visualizações presentes no notebook auxiliam na identificação de padrões e tendências e tornam os resultados mais fáceis de interpretar.

## Como executar o projeto

Clone este repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Acesse a pasta do projeto:

```bash
cd analise-de-dados-loja
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute o Jupyter Notebook:

```bash
jupyter notebook
```

Em seguida, abra o arquivo localizado em:

```text
notebooks/analise_loja.ipynb
```
